# Fairshare Chores

## What is this?
A simple web app that helps families distribute household chores fairly - based on difficulty points, not just whoever gets asked first. 

## Why I built it?
Honestly? I'm usually the one who ends up doing the most chores at home. My parents would ask one of us to help, and somehow it was always me 😅

So I built this for my family - a simple way to track who's doing what, make sure the workload is balanced, and (hopfully) prove that I'm not the only one who should be doing the dishes.

## How to use it?
1. Add your family members
2. Add chores and their difficulty points (1-5)
3. Click "Assign Chores Fairly"
4. Mark chores as done when completed

## Tech used
- HTML
- CSS
- JavaScript
- localStorage for data persistence
